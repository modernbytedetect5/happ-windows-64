# Contributing

Thank you for your interest in **happ-windows-64**.

## Source code

This repository is a **packaging / documentation mirror**, not the main
development tree. To contribute code to the application itself, use the
upstream repository:

**[Happ-proxy/happ-desktop](https://github.com/Happ-proxy/happ-desktop)**

## Contributions welcome here

- Fixes to README, `docs/`, translations
- Clearer install instructions for Windows portable
- Issue reports about release archive names or broken links

## Pull requests

1. Fork this repository
2. Edit documentation only (no binary commits in PRs)
3. Describe what you changed and why
4. Open a pull request with a short summary

## Code of conduct

Please be respectful in issues and pull requests. See `CODE_OF_CONDUCT.md`.
