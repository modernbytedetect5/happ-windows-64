# Security Policy

## Supported versions

| Release | Supported |
| :--- | :--- |
| Latest on [Releases](../../releases/latest) | yes |
| Older tags | no |

## Reporting a vulnerability

Security issues in the **upstream application** should be reported to the
official project:

- Repository: [Happ-proxy/happ-desktop](https://github.com/Happ-proxy/happ-desktop)
- Website: https://www.happ.su/main

For problems with **this mirror** (broken download, wrong archive name,
README only):

1. Open an issue in this repository with steps to reproduce
2. Do not post exploit details publicly before a fix is available

## Safe download

- Use only files from **Releases → Latest**
- Verify the archive name matches **`happ_windows.zip`**
- After extract, run **`happ_windows.exe`** from the folder inside the zip
